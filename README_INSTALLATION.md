# 🛡️ SafeWeb Pro - Инструкция по установке

## ✅ Все изменения успешно применены!

### Что было улучшено:

1. **Линии безопасности под ссылками**
   - Теперь цветная линия отображается ПОД текстом ссылки
   - Для inline-ссылок используется `border-bottom`
   - Для блочных элементов создается отдельный декоративный элемент

2. **Автоматическая проверка файлов не из базы**
   - Добавлена функция `calculateSafetyScore()` для расчета балла безопасности
   - Анализ неизвестных доменов по множеству критериев:
     - Длина доменного имени
     - Наличие цифр и дефисов
     - Тип доменной зоны (TLD)
     - Подозрительные ключевые слова (login, secure, verify и т.д.)

3. **Балл безопасности в tooltip**
   - При наведении на ссылку отображается балл от 0 до 100
   - Цветная шкала прогресса показывает уровень безопасности
   - Цвет меняется в зависимости от балла:
     - 🟢 80-100: Зеленый (безопасно)
     - 🟡 60-79: Желто-зеленый (относительно безопасно)
     - 🟠 40-59: Оранжевый (сомнительно)
     - 🔴 0-39: Красный (опасно)

## 🔧 Установка расширения в браузер

### Для Google Chrome / Яндекс.Браузер / Edge:

1. **Подготовьте файлы**
   - Убедитесь, что все файлы находятся в одной папке:
     ```
     safeweb-pro/
     ├── manifest.json
     ├── popup.html
     ├── popup.css
     ├── popup.js
     ├── background.js
     ├── content.js
     ├── content-links.js
     ├── content-search.js
     ├── content-email-warning.js
     └── database.js
     ```

2. **Откройте страницу расширений**
   - Chrome: Перейдите на `chrome://extensions/`
   - Яндекс: `browser://extensions/`
   - Edge: `edge://extensions/`

3. **Включите режим разработчика**
   - В правом верхнем углу включите переключатель "Режим разработчика"

4. **Загрузите расширение**
   - Нажмите кнопку "Загрузить распакованное расширение"
   - Выберите папку с файлами расширения
   - Расширение появится в списке

5. **Проверьте работу**
   - Значок расширения должен появиться в панели браузера
   - Откройте любой сайт и наведите курсор на ссылку
   - Должен появиться tooltip с информацией о безопасности

## 🎯 Проверка новых функций

### 1. Линии под ссылками
- Откройте любой сайт со ссылками (например, google.com)
- Наведите курсор на любую внешнюю ссылку
- Под ссылкой должна появиться цветная полоса:
  - 🟢 Зеленая = безопасно
  - 🟠 Оранжевая = неизвестный сайт
  - 🔴 Красная = опасно

### 2. Балл безопасности
- При наведении на ссылку посмотрите на tooltip
- Внизу должна быть шкала с баллом (например, "75/100")
- Попробуйте разные сайты:
  - `youtube.com` → ~95-98 баллов
  - `google.com` → ~98 баллов
  - Неизвестный сайт → 40-70 баллов (в зависимости от характеристик)

### 3. Автоматический анализ
- Перейдите на сайт с неизвестными доменами
- Система автоматически рассчитает балл на основе:
  - Длины домена
  - Наличия подозрительных символов
  - Доменной зоны
  - Ключевых слов в названии

## 🐛 Устранение проблем

### Расширение не загружается
- Проверьте, что все файлы в одной папке
- Убедитесь, что `manifest.json` корректный
- Проверьте консоль ошибок на странице `chrome://extensions/`

### Tooltip не появляется
- Обновите страницу (F5)
- Проверьте, что скрипт `content-links.js` загружен
- Откройте консоль разработчика (F12) и проверьте ошибки

### Балл не отображается
- Убедитесь, что `background.js` правильно загружен
- Проверьте консоль на наличие ошибок
- Перезагрузите расширение на странице `chrome://extensions/`
